### ETC料金・休日割引比較（2026-10-19）

- 静波往路（西名阪・松原〜天理840円、名阪国道無料、亀山〜吉田5,510円）：通常6,350円／深夜4,450円／休日4,700円。
- 静波復路（吉田IC〜吹田IC、新名神・名神経由）：通常7,480円／深夜5,240円／休日5,560円。大阪近郊の対象外区間のため休日割引は一律30％にはならない。
- 往復の通常ETCは13,830円、往復とも休日割引対象の場合10,260円、往復とも深夜割引対象の場合9,690円。なんば駅〜松原ICの市内高速、途中下車、駐車場は別。
- GW・お盆・年末年始・シルバーウィーク・3連休は休日割引適用除外。休日割引と深夜割引の重複なし。2026年度の対象日はNEXCO公式日程を確認。
- サイト内：`shizunami-drive/index.html#toll-fees` と `shizunami-drive/night-discount.html#toll-prices` に比較表を掲載。予算表は通常ETC 13,830円の参考額で計算。

### Googleマップ1タップ・往復ルート（2026-10-19）

- `shizunami-drive/index.html`：ファーストビュー、ルート欄、固定ボトムナビの「行きMAP」「帰りMAP」からGoogleマップの運転ルートを1回押して開く。
- 行き：なんば駅→道の駅針テラス（名阪国道を選びやすくする経由地）→刈谷ハイウェイオアシス→静波海岸。
- 帰り：静波海岸→新名神・土山SA（下り）→名神・吹田IC→新御堂筋・千里IC→なんば駅。
- 全4ページ共通のハンバーガーメニューにも直接Googleマップを開く項目を追加。Google Maps URLs API の `api=1`／`origin`／`destination`／`waypoints`（モバイルブラウザ上限3）／`travelmode=driving` を使用。
- 交通規制やGoogleマップの経路再計算で指定道路が外れる可能性があるため、発車前にルートと経由地を確認。Googleマップ上でナビ開始操作は別途必要な場合がある。
