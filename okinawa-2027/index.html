FAMILY REQUEST / 3 OPTIONS

家族の希望候補を追加！

LINEで届いた3施設。いまの6日間に無理に追加せず、既存コースと比較して選べるようにしました。気になる場所にチェックすると、この端末にだけ保存されます。

結論｜1月18日と19日の「入れ替え候補」

1/18（月）はClub Savvyランチを先に食べてから「北谷」「沖縄こどもの国」「海中道路・ぬちまーす」のいずれか1つ。1/19（火）は無料ランチ後にオリオン14時見学を予約できれば、15:45頃パイナップルパークも候補。ただし余裕がなければ片方に絞る。ホテル3連泊と17時のレンタカー返却時刻は維持します。

希望候補 1 / 未採用

名護市・名護工場

オリオンハッピーパーク

大人1,000円×2＋7〜19歳350円×2 = 2,700円

ビール工場のガイド見学とショップ。子どもにはソフトドリンクが用意され、運転者はアルコール試飲不可。美ら海水族館を21日に移したため、19日午後の名護方面で検討。14時の予約が取れた場合、パイナップルとの組み合わせも可能ですが移動時間に注意。

希望候補 2 / 未採用

うるま市・宮城島

ぬちまーす観光製塩ファクトリー

工場見学無料／食事・お土産別

塩の製造工程を見学したあと、敷地内の絶景「果報バンタ」へ。海中道路ドライブとセットで楽しむ場所。北谷のアメリカンビレッジを残したままだと大きく遠回りになるため、入れ替えがおすすめ。

組み込みやすい日1/18（月）｜ランチ後の東海岸ドライブ候補
営業時間・条件9:00〜17:30／無料ガイド10〜15分／4人なら予約不要
事前チェック

写真は工場ではなく、立ち寄り途中の海中道路。果報バンタの散策は約15分。

希望候補 3 / 未採用

沖縄市・動物園

沖縄こどもの国

16歳以上1,000円×2／15歳以下無料 → 2,000円

動物園や体験施設を家族で楽しめるスポット。雨や子どもの興味に合わせて検討。ただし園内は広いため、1〜2時間で急いで回るより、半日近く取るほうが満足度が高い。
