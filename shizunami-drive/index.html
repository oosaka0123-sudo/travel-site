DRIVING ROUTE

なんば駅 → 静波海岸

静波海岸は静岡県牧之原市にあります。東名吉田ICまたは相良牧之原ICが静波海岸への入口です。

なんば駅 → 大阪市内の接続道路 → 西名阪道 → 名阪国道（R25・無料） → 東名阪道 → 伊勢湾岸道 → 東名高速 → 吉田IC → 静波海岸
※なんば駅から西名阪道へのアクセスは、阪神高速などを利用する場合があり別料金です。
おすすめ・寄り道少なめ

東名 → 吉田IC → 静波

刈谷PAで休憩後、東名高速を東へ。吉田ICから一般道を約15分進むと静波海岸です。

RETURN TRIP / SHIZUNAMI → OSAKA

帰りは新名神から吹田へ。

行きの「西名阪・名阪国道」と帰りの「新名神・名神」は別ルート。吹田ICで降りて新御堂筋を南下し、なんば駅を目指します。

静波海岸 → 東名・吉田IC → 東名高速（名古屋方面） → 豊田JCT → 伊勢湾岸道 → 四日市JCT → 新名神 → 草津JCT → 名神高速 → 吹田IC → 大阪中央環状線 → 千里IC → 新御堂筋（国道423号・梅田方面） → 梅田 → 市内一般道 → なんば駅
① 静岡 → 大阪・高速道路

東名 → 伊勢湾岸 → 新名神 → 名神

静波海岸から一般道で吉田ICへ。豊田JCTで伊勢湾岸道に入り、四日市JCTから新名神に進みます。草津JCTで名神高速へ接続し、吹田ICで高速を降ります。

経路チェック：土山SA（新名神）をナビの経由地に入れると、名阪国道に戻る経路との混同を防ぎやすくなります。

📍 高速区間をナビ ↗NEXCOで料金照会 ↗
② 吹田IC → なんば・一般道

吹田で降りて、新御堂筋

名神・吹田ICで下車後、大阪中央環状線などを使って新御堂筋・千里IC付近へ。新御堂筋（国道423号）を南へ進み、梅田からは一般道で難波駅に向かいます。

「吹田IC＝新御堂筋の入口」ではなく、間に一般道の移動がある点に注意。新御堂筋は梅田方面までの道路です。

MODEL ITINERARY

1泊＋運転休憩のモデル

到着時刻は交通状況と出発時刻で変わるため、時刻を固定せず無理のない順番だけ掲載しています。

01
なんば駅を出発

西名阪・名阪国道経由で東へ。途中SAで適宜休憩。

02
刈谷PAで温泉・遊び

100円遊具が目的なら営業中に到着。夜遅ければ温泉や観覧車も当日営業時間を確認。

03
必要なら運転休憩・仮眠

SA・PAでの長時間の宿泊利用は避ける。運転疲れや子どもの状態に応じて宿泊施設も検討。

04
途中テーマパークを1か所

のんほいパーク、エアーパーク浜松、掛川花鳥園などから選択。

05
吉田IC → 静波海岸

静波の海辺を散策。サーフスタジアムの見学やカリーフォルニア ハグでのランチも候補（L.O.14:30目安）。

06
静波エリアで宿泊・帰路へ

家族4人で予約できる客室を確認。帰路は新名神→名神・吹田IC→新御堂筋でなんば駅へ。
